# MaGuru Core — Посібник користувача

**Версія:** 1.1.6  
**Сумісність:** Adobe Commerce / Magento Open Source 2.4.4 – 2.4.x  
**PHP:** 8.1 або вище  
**Ліцензія:** Безкоштовна

---

## Огляд

MaGuru Core — це **базовий модуль** для всіх розширень MaGuru. Він не додає власних функцій вітрини. Натомість він надає спільну інфраструктуру, на яку покладається кожен інший модуль MaGuru, а також додає окремий розділ **MaGuru** в адмінку конфігурації Magento, звідки керуються всі модулі MaGuru з одного місця.

Після встановлення в **Stores → Configuration** з'являється вкладка **MaGuru**, а також нова панель **Extensions**, що показує всі встановлені модулі MaGuru одним поглядом.

---

## Що робить модуль

- Створює вкладку **MaGuru** в **Stores → Configuration** — єдиний дім для налаштувань усіх розширень MaGuru
- Додає панель **Extensions Overview** у **Stores → Configuration → MaGuru → Extensions**, що показує кожен встановлений модуль MaGuru з його версією, посиланнями на список змін та документацію
- Надає спільну інфраструктуру HTTP-клієнта, конфігурації, логування та обробки помилок, яку використовують усі модулі MaGuru
- Не має власних функцій, орієнтованих на клієнта

## Встановлення

### Крок 1 — Встановлення через Composer

Виконайте наступні команди з кореневої директорії вашого Magento:

```bash
composer require maguru/magento2-core
bin/magento setup:upgrade
bin/magento setup:di:compile
bin/magento cache:flush
```

> **Примітка:** Якщо ваш магазин працює в режимі production, також виконайте `bin/magento setup:static-content:deploy` після компіляції.

### Крок 2 — Перевірка встановлення

```bash
bin/magento module:status MaGuru_Core
```

Вивід має показати `Module is enabled`.

## Панелі адмінки

### Extensions Overview

**Stores → Configuration → MaGuru → Extensions**

Ця панель — центральна панель управління екосистемою розширень MaGuru. Вона відображає таблицю всіх модулів MaGuru, знайдених у вашому встановленні.

| Колонка | Опис |
|---|---|
| **Extension Name (Назва розширення)** | Назва розширення MaGuru |
| **Version (Версія)** | Поточна встановлена версія. Якщо доступна новіша версія, з'являється індикатор оновлення (напр., `1.0.1 → 1.0.2`) |
| **Stability (Стабільність)** | Бейдж стабільності релізу: Stable, Beta, Alpha або Dev |
| **Dev Status (Статус розробки)** | Бейдж статусу розробки: In Development, Ready, For Sale або Public Repo |
| **Changelog (Список змін)** | Посилання на історію версій цього розширення |
| **User Guide (Посібник користувача)** | Посилання на документацію цього розширення |
| **Download (Завантаження)** | Посилання на завантаження останньої версії (якщо застосовно) |

#### Розділ Installed Extensions

Показує всі модулі MaGuru, наразі встановлені на вашому екземплярі Magento, з номерами версій та посиланнями.

#### Розділ New Extensions

Показує розширення MaGuru, які доступні, але ще не встановлені на вашому магазині. Використовуйте посилання Download, щоб отримати пакет і встановити його через Composer.

> **Примітка:** Індикатори оновлення версії мають лише інформаційний характер — вони не запускають автоматичні оновлення. Оновлення завжди виконуються вручну через Composer, як описано в документації кожного розширення.

## Часті запитання

**Q: Я встановив цей модуль, але не бачу нових функцій на вітрині. Це нормально?**

Так. MaGuru Core — це інфраструктурний модуль, він не має функцій, орієнтованих на вітрину. Його мета — забезпечити роботу всіх інших розширень MaGuru. Встановіть функціональні модулі MaGuru (наприклад, eSputnik Backend, Monobank Payment, Checkbox Fiscal або RZ-Delivery), щоб додати функції у ваш магазин.

---

**Q: Панель Extensions показує деякі розширення в "New Extensions". Що це означає?**

Ці розширення доступні в каталозі MaGuru, але ще не встановлені у вашому магазині. Щоб встановити одне з них, використовуйте Composer:

```bash
composer require maguru/<module-package-name>
bin/magento setup:upgrade
bin/magento setup:di:compile
bin/magento cache:flush
```

Зверніться до посилання User Guide, показаного поруч із кожним розширенням, для повних інструкцій зі встановлення.

---

**Q: Розширення показує "1.0.1 → 1.0.2" у колонці Version. Що це означає?**

Це означає, що доступна новіша версія цього розширення. Натисніть посилання Changelog, щоб переглянути зміни. Коли будете готові оновити, виконайте `composer update maguru/<package-name>`, а потім `bin/magento setup:upgrade && bin/magento cache:flush`.

---

**Q: Я бачу вкладку "MaGuru" в конфігурації, але жоден з інших модулів MaGuru не показує там своїх налаштувань. Чому?**

Кожен модуль MaGuru додає власну групу конфігурації до вкладки MaGuru після встановлення. Якщо у вас встановлено лише MaGuru Core, з'являється лише панель **Extensions**. Встановіть відповідний модуль, щоб побачити його налаштування.

---

**Q: Чи можу я видалити MaGuru Core, залишивши інші модулі MaGuru?**

Ні. Усі модулі MaGuru залежать від MaGuru Core. Видалення цього модуля зламає всі інші розширення MaGuru. Якщо ви хочете вимкнути конкретне розширення, вимкніть або видаліть саме той окремий модуль, а не Core.

## Підтримка

Якщо ви зіткнулися з проблемою:

1. Перевірте, що `bin/magento module:status MaGuru_Core` повертає `enabled`
2. Перевірте, що вкладка **MaGuru** з'являється в **Stores → Configuration**
3. Зверніться до підтримки з версією Magento, версією PHP та описом проблеми
